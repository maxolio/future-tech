# Правила и контекст проекта Future Tech

## Стек проекта
- Разметка: HTML5 (семантическая).
- Стили: SCSS/SASS (компиляция через `npm run sass-watch`).
- Скрипты: Vanilla JavaScript в папке `scripts/`.
- Локальный сервер: `live-server` (`npm start`).

## Градация поведения по сложности задач

### 1. Простые и рутинные задачи (Быстрый режим / Flash):
- Примеры: правка селекторов, добавление HTML-блока, стилизация элементов по макету, исправление опечаток.
- Поведение: сразу предлагать точечный diff или фрагмент кода с кратким пояснением.

### 2. Сложные задачи (Режим планирования / Deep Reasoning):
- Примеры: рефакторинг архитектуры стилей (БЭМ/ITCSS), создание сложной JS-логики/анимаций, кроссбраузерная адаптивность, реорганизация структуры проекта.
- Поведение:
  1. **Сначала план**: провести анализ затронутых файлов и составить пошаговый план без внесения правок в код.
  2. **Согласование**: дождаться одобрения плана пользователем.
  3. **Пошаговое выполнение**: реализовывать задачу шаг за шагом.
  4. При необходимости масштабного поиска по файлам использовать субагента (`research`), чтобы не засорять основной контекст.

## Обязательные ограничения
- Всегда отвечать на русском языке.
- **СТРОГО ЗАПРЕЩЕНО** редактировать или создавать файлы без явного подтверждения от пользователя.
- Не ломать существующие пути к ресурсам (`fonts/`, `icons/`, `images/`).
- При изменении SCSS помнить о сборщике SASS и структуре импортов.
