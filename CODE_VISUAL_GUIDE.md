# Визуальный справочник разработчика (Code Visual Guide)

Инженерная шпаргалка с ментальными моделями, физикой браузера и оценкой нагрузки на систему для CSS, JS и HTML.

---

### Градиентная рамка со скруглением (`background-clip: padding-box`)

```scss
border: rem(1) solid transparent;
background: 
  linear-gradient(var(--color-dark-10), var(--color-dark-10)) padding-box,
  var(--badge-gradient);
```

* **Образ:** «Сэндвич из двух слоёв». Снизу лежит яркий градиент на всю ширину (до внешнего края `border-box`), сверху на него наложен тёмный прямоугольник поменьше (обрезанный по внутреннему краю `padding-box`), а через 1px прозрачной рамки выглядывает яркая кромка.
* **Геометрия и поток (Layout):** Рамка `border: 1px solid transparent` честно резервирует 1px с каждой стороны в Box Model. На соседей влияния нет (размеры элемента стабильны).
* **Нагрузка на систему (Performance):**
  * 🟢 **Reflow:** Отсутствует при загрузке (если размеры статичны).
  * 🟠 **Repaint:** Браузер вычисляет два слоя фона и применяет обрезку (`clip`). Нагрузка мизерная, абсолютно безопасна.
* **Каскад и архитектура:** Не требует псевдоэлементов (`::before` / `::after`), оставляя их свободными для иконок или анимаций. Отлично сочетается с `border-radius`.
* **Ограничение (Важно):** Метод применим **только для непрозрачных (solid) фонов**. Если фону задать прозрачность, нижний градиент просветит насквозь по всей площади блока.
* **Вердикт:** Золотой стандарт индустрии для создания градиентного бордера у кнопок и бейджей с закругленными углами.

## 🎨 CSS

### `.header { display: none !important; }`

* **Образ:** «Выдернутый кирпич». Элемент физически исчезает с экрана, как будто его стёрли из разметки.
* **Геометрия и поток (Layout):** Пространство **схлопывается**. Весь контент снизу мгновенно поднимается вверх, занимая место шапки (координата `Y` следующего блока становится `0`).
* **Нагрузка на систему (Performance):**
  * 🔴 **Reflow (Тяжёлая):** Вызывает полный перерасчёт геометрии страницы. Браузер заново вычисляет координаты и размеры всех элементов, шедших ниже по потоку.
  * 🟠 **Repaint (Средняя):** Браузер перерисовывает пиксели в области, где раньше находилась шапка.
* **Доступность и DOM (a11y):**
  * В HTML-дереве (DOM) элемент **остаётся** (JS может найти его через `querySelector`).
  * Из Accessibility Tree (для скринридеров) **удаляется полностью** (незрячие пользователи о нём не узнают, табом на ссылки внутри шапки попасть нельзя).
  * Мышь сквозь пустое место кликает по блокам, которые поднялись наверх.
* **Каскад и архитектура (`!important`):** «Абсолютный приоритет». Ломает стандартный каскад CSS. Перебить это свойство другим классом невозможно — потребуется писать ещё один селектор с `!important` или инлайновый стиль.
* **Вердикт:** Подходит для статического скрытия элементов на определённых разрешениях экрана (в `@media`). Не рекомендуется часто переключать туда-обратно через JS на лету из-за микрофризов от Reflow.
