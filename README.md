# 🌐 Future Tech — Информационный портал о технологиях будущего

Адаптивный многофункциональный веб-сайт (блог-платформа), посвященный технологическим трендам, подкастам, видеообзорам и аналитическим отчетам. Проект создан для портфолио с целью демонстрации навыков построения сложной семантической разметки, работы с большим объемом медиаконтента, адаптивного дизайна и реализации интерактивных интерфейсов.

---

## 🛠️ Стек технологий и инструменты
* **HTML5** — семантическая разметка для обеспечения доступности и SEO (использование тегов `header`, `main`, `section`, `article`, `aside`, `footer` и др.).
* **CSS3 / SCSS** — модульная стилизация интерфейса, построение гибких сеток (Flexbox, CSS Grid) и адаптивность под различные типы устройств.
* **BEM (БЭМ)** — методология именования классов для поддержки независимости компонентов и масштабируемости стилей.
* **JavaScript (ES6+)** — интерактивные компоненты (навигация, вкладки, интерактивные формы, кастомные элементы управления медиаплеерами).
* **Git & GitHub** — контроль версий, фиксация этапов разработки и публикация проекта.
* **Repomix** — инструмент для оптимизации и упаковки контекста проекта перед передачей в LLM.

<summary>
 Этап 2: Настройка структуры стилей, подключение хелперов и исправление путей
</summary>

На данном этапе был наведен порядок в стилях, добавлены полезные инструменты для верстки и исправлены пути к файлам для корректной работы сайта.

* **Наведение порядка в файлах**:
    * Стили разделены по папкам: базовые перенесены в `styles/base/` (шрифты, переменные, глобальные правила и сброс стилей), также созданы пустые папки `components/` (для блоков типа кнопок и шапки) и `pages/` (для уникальных стилей страниц).
    * Импорты переведены на современный синтаксис Sass (`@use` и `@forward`) через файлы `_index.scss`. Это решило проблемы с ошибками компиляции на Windows.

* **Подключение вспомогательных инструментов (`styles/helpers/`)**:
    * Глобальные стили соединены с готовым набором функций и миксинов для ускорения верстки:
        * **Функции `rem` и `fluid`** — для автоперевода пикселей в rem и создания плавных, «резиновых» размеров.
        * **Миксин `fluid-text`** — для плавной адаптации размеров шрифта под разные экраны.
        * **Миксины `hide`/`show`** — для аккуратного и плавного скрытия элементов в анимациях.
        * **Миксины выравнивания (`flex-center`, `abs-center`, `square`)** — для быстрого позиционирования элементов и задания размеров.
        * **Миксин `visually-hidden`** — для скрытия текста от пользователей с сохранением его для поисковиков (SEO).
        * **Миксин `hover`** — для правильной работы эффектов наведения на мобильных устройствах (без «залипания» при касании).

* **Исправление путей к шрифтам**:
    * Абсолютные пути к шрифтам (`/fonts/...`) заменены на относительные (`../fonts/...`), чтобы они правильно загружались и локально, и после загрузки проекта на GitHub Pages.

<summary>
 Этап 3: Создание адаптивной шапки сайта (Header) и реализация интерактивных скриптов
</summary>

На данном этапе завершена верстка и стилизация глобального компонента шапки, созданы базовые UI-элементы и написан скрипт для динамического отслеживания геометрии интерфейса.

* **Разметка и стилизация UI-компонентов (`styles/components/`)**:
    * **`_header.scss`** — реализована Flexbox-сетка шапки. Настроена фиксация (`position: sticky`) с учетом высоты скрывающегося промо-баннера. Сверстано адаптивное мобильное меню, переходящее в полноэкранный оверлей на экранах менее 768px.
    * **`_button.scss`** — созданы стили для базовых кнопок и ссылок проекта (прозрачные кнопки с рамками и заливочные акцентные кнопки с плавными эффектами наведения).
    * **`_burger-button.scss`** — сверстана кнопка-меню для мобильной версии с плавным переходом (`transition`) горизонтальных линий в крестик при активации.
    * **`_logo.scss`** и **`_icon.scss`** — настроены адаптивные размеры логотипа и иконок-стрелок с переходом на единицы `rem` и `fluid` для масштабируемости.

* **Интерактивный JavaScript (`scripts/`)**:
    * **`Header.js`** — написан компонент для управления состоянием мобильного меню (добавление классов активности, блокировка скролла страницы при открытом меню).
    * **`HeaderScroll.js`** — реализован универсальный наблюдатель высоты элементов (`ResizeObserver`). Скрипт динамически считывает физическую высоту промо-баннера из HTML-атрибута `data-js-element-observer` и передает значение в CSS-переменную `--header-promo-height` в реальном времени.

<summary>
 Этап 7: Разработка интерактивного компонента вкладок (Tabs) с реактивным состоянием и поддержкой A11y
</summary>

На данном этапе реализована полностью доступная система вкладок на чистом JavaScript (ES6+ модули) с реактивным обновлением интерфейса и поддержкой управления с клавиатуры.

* **Архитектура и реактивность (`scripts/Tabs2.js`)**:
    * Реализован паттерн **State-driven UI**: состояние активного таба инкапсулировано в `Proxy`, благодаря чему метод перерисовки `updateUi()` вызывается автоматически при любом изменении `this.state.activeTabIndex`.
    * Создан класс-коллектор `Tabs2Collections` (паттерн «Фабрика») для автоматического поиска по data-атрибутам `[data-js-tabs]` и независимой инициализации всех блоков табов на странице.

* **Доступность (WAI-ARIA & A11y)**:
    * Настроена семантическая связка атрибутов: `role="tablist"`, `role="tab"`, `role="tabpanel"`, а также управление контекстом через `aria-controls` и `aria-labelledby`.
    * Автоматическая синхронизация атрибута `aria-selected` и управление фокусом через `tabindex="0" / "-1"`.

* **Клавиатурная навигация**:
    * Реализовано циклическое переключение вкладок стрелками (`ArrowLeft` / `ArrowRight`) с автоматическим переносом фокуса (`.focus()`).
    * Добавлен быстрый переход к первой и последней вкладкам по клавишам `Home` / `End`, включая поддержку шорткатов macOS (`Cmd + ArrowLeft` / `Cmd + ArrowRight`).

</details>
